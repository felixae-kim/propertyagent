## 2. TAM / SAM / SOM 추정

### TAM (Total Addressable Market) - 전체 시장

**한국 부동산 정보 서비스 시장**
- 부동산 앱 이용자: 약 500만명 이상 (2025년 기준 주요 4개 앱 MAU 합산)
- 전국 아파트 보유 가구: 약 1,100만 가구 [가정]
- 추정 TAM: **약 5,000억원~1조원/년** (부동산 정보 서비스, 중개 수수료, 광고 포함) [가정]

### SAM (Serviceable Addressable Market) - 접근 가능 시장

**아파트 매매/투자 정보 앱 시장**
- 대상: 아파트 매매에 관심 있는 사용자 (매수 예정자 + 투자자)
- 아파트 매매 연간 거래량: 약 50~70만건/년
- 관련 앱 MAU 합산: 약 650만명 (중복 제거 시 약 350~400만명 추정) [가정]
- 추정 SAM: **약 1,500억원~3,000억원/년** (광고, 프리미엄 구독, 제휴 수익) [가정]

### SOM (Serviceable Obtainable Market) - 실현 가능 시장

**스마트 매물 알림 + 큐레이션 서비스**
- 대상: 조건 기반 맞춤 매물 알림을 원하는 적극적 탐색자/투자자
- 초기 타겟 MAU: 10~30만명 (출시 후 1~2년)
- 추정 SOM: **약 50억원~150억원/년** (프리미엄 구독 + 광고 + 제휴) [가정]

> [검증 필요] TAM/SAM/SOM 수치는 공개 데이터 기반 추정치이며, 상세 시장 조사를 통한 검증이 필요합니다.

## 5. 기회 분석 (Opportunity Scoring)

### Opportunity Score = Importance + (Importance - Satisfaction)
- Importance: 사용자에게 해당 기능이 얼마나 중요한지 (1-10)
- Satisfaction: 현재 시장에서 얼마나 잘 충족되고 있는지 (1-10)
- Score가 높을수록 미충족 수요가 큰 기회

| # | 기회 (Opportunity) | Importance | Satisfaction | Score | 영향 받는 사용자 세그먼트 |
|---|-------------------|-----------|-------------|-------|----------------------|
| 1 | **매물 지정가 알림** | 9 | 2 | 16 | A, B |
| 2 | **조건 조합 매물 알림** | 9 | 2 | 16 | A, B |
| 3 | **교통 호재 시각화** | 7 | 5 | 9 | B |
| 4 | **인플루언서 픽 단지** | 6 | 1 | 11 | B, C |
| 5 | **커머스형 부동산 탐색** | 8 | 3 | 13 | A, C |

### 점수 산정 근거

**1. 매물 지정가 알림 (Score: 16)**
- Importance 9: 매수 타이밍이 가격 협상의 핵심. 희망 가격 매물을 실시간으로 잡는 것은 수천만원 차이.
- Satisfaction 2: 어떤 앱도 "지정가" 방식의 매물 알림을 제공하지 않음. 네이버부동산은 새 매물 알림만, 아실은 가격변동 알림만 제공.

**2. 조건 조합 매물 알림 (Score: 16)**
- Importance 9: 지역+세대수+학군+금액의 복합 조건은 실제 매수 의사결정의 핵심 변수.
- Satisfaction 2: 다방의 AI 방찾기가 부분적으로 유사하나 아파트 매매에는 부적합. 대부분 단일 조건 필터만 지원.

**3. 교통 호재 시각화 (Score: 9)**
- Importance 7: 투자자에게 교통 호재는 핵심 판단 요소이나, 전체 사용자 중 투자자 비율은 일부.
- Satisfaction 5: 호갱노노가 개발호재 기능을 이미 제공. 다만 시각적 완성도와 상세도에서 개선 여지 있음.

**4. 인플루언서 픽 단지 (Score: 11)**
- Importance 6: 유튜버 추천은 참고 정보로 유용하나, 맹신 위험 + 책임 이슈 존재.
- Satisfaction 1: 유튜버 추천 단지를 앱 내에서 바로 확인하는 서비스는 전무.

**5. 커머스형 부동산 탐색 (Score: 13)**
- Importance 8: 기존 앱들의 UI가 전문가 중심으로 복잡. 특히 입문자에게 진입 장벽 높음.
- Satisfaction 3: 직방 VR 투어가 일부 충족하나, 전반적으로 "쇼핑하듯 직관적인" 경험은 부재.

## 7. Gap Analysis: 시장 빈틈 요약

### 확인된 White Space (시장 공백)

1. **"주식 지정가 주문" 방식의 부동산 매물 알림은 존재하지 않음**
   - 주식 앱에서는 당연한 기능이 부동산에는 없음
   - 사용자가 원하는 가격을 설정하고 기다리는 "수동적 탐색" 패턴 미충족
   - 이것이 가장 큰 시장 공백

2. **복합 조건 기반 자동 매칭 알림 부재**
   - "초품아 + 500세대 이상 + 7억 이하 + 강남 30분 이내"와 같은 복합 조건 알림은 어떤 앱에도 없음
   - 사용자들은 여러 앱을 오가며 수동으로 크로스체크

3. **부동산 탐색의 UX 혁신 부재**
   - 모든 경쟁 앱이 "지도 + 리스트" 패러다임
   - 쿠팡/무신사 같은 "발견의 즐거움"이 있는 커머스형 경험 없음
   - 입문자를 위한 쉬운 UX가 시장에 없음

4. **콘텐츠 크리에이터 x 부동산 데이터 결합 없음**
   - 유튜버 추천 단지를 앱에서 바로 실거래가/시세와 함께 확인하는 서비스 전무
   - 단, 법적/윤리적 리스크 검토 필요 (뒷광고, 투자 책임 등)

### 경쟁 위협 (Competitive Threats)

1. **네이버 생태계 강화**: 네이버페이의 아실 인수(2025)로 네이버부동산+아실 결합 시 데이터+매물+금융 통합 플랫폼 등장 가능
2. **직방+호갱노노 시너지**: 매물(직방) + 분석(호갱노노) 통합이 가속화될 경우 우리 서비스의 차별화 공간 축소
3. **AI 기술의 범용화**: AI 매물 추천이 범용화되면 기술적 차별화 어려움

## 8. 전략적 권고 (Strategic Recommendations)

### MVP 핵심 가치 제안

> "원하는 아파트, 원하는 가격에 나올 때 알려드립니다"

**1번(지정가 알림)과 2번(조건 조합 알림)을 결합하여 하나의 핵심 기능으로 개발하고, 5번(커머스형 탐색)을 전체 UX 방향성으로 설정하는 것을 권고합니다.**

### 차별화 전략

| 기존 앱 | 우리 서비스 |
|---------|----------|
| 사용자가 직접 매물을 찾아야 함 | 조건 설정 후 매물이 사용자를 찾아옴 |
| 지도+리스트 UI | 커머스형 "발견" UI |
| 전문가 중심 용어 | 말하듯이 쓰기 (토스 원칙) |
| 앱 여러개 크로스체크 | 하나의 앱에서 시세+학군+교통+매물 |

### 진입 타이밍 평가

| 요소 | 평가 |
|------|------|
| 시장 성장 | 유리 - 거래량 증가 추세, 공급 절벽으로 탐색 수요 상승 |
| 경쟁 환경 | 주의 - 네이버+아실, 직방+호갱노노 통합 가속 |
| 기술 환경 | 유리 - 공공 데이터 API 개방, AI 기술 접근성 향상 |
| 사용자 준비도 | 유리 - 주식 앱 경험으로 지정가 알림 개념에 익숙 |

**결론: 진입 타이밍은 적절하나, 대형 플랫폼의 M&A 통합이 완성되기 전에 빠른 MVP 출시가 중요합니다.**
